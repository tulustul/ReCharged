# ReCharged

*Small cars. Big world. Full charge.*

ReCharged is an arcade combat racer for 1:10 electric RC cars tearing through giant everyday
worlds — a toy store, a family house, a back garden, a supermarket after closing, an auto-repair
workshop and a suburban street. It is inspired by Re-Volt but is its own game: original cars,
tracks and items built around a **battery-charge** boost mechanic, dynamic weather and time of
day, a modern React UI and split-screen for up to four players.

Built with **Rust + [Bevy 0.20](https://bevy.org)**, **[bevy-react](https://github.com/tulustul/bevy-react)
0.8** (all menus and the HUD are React rendering to `bevy_ui`), **bevy_rapier3d** (physics) and
**bevy_kira_audio** (audio). Every model, texture, sound effect and music track is generated by
scripts in `tools/`.

## Features
- 8 RC cars (buggy, monster truck, touring, muscle, rally hatch, coupe, hypercar, secret formula)
  with ray-cast suspension physics, drift assists, air control and auto-righting.
- 6 tracks × Forward / Reverse × Mirror = 24 layouts, each with jumps, shortcuts and a hidden
  Golden Battery.
- 10 items: Turbo Cell, Spark Rocket, Leech Coil, Shock Orb, EMP Pulse, Goo Bomb, Oil Slick,
  Spring Pad, Shield Bubble, Storm Strike — position-weighted odds, shields and lock-on warnings.
- Charge & boost: drift, jump and draft to fill your battery, spend it on the straights.
- 7 named AI rivals at four difficulties with personalities, catch-up and stuck recovery.
- Modes: Championship (4 cups), Quick Race, Time Trial (ghosts, medals), Versus (2–4 players).
- Progression: cups unlock cars, tracks, reverse/mirror, difficulties and paint sets; records,
  medals, trophies and stats are saved.
- Weather (clear, cloudy, rain, storm, fog, snow — with wet/snowy grip) and four times of day.
- Split-screen for 1–4 players with keyboard (two schemes) and gamepads, full rebinding.
- Settings that apply live: graphics presets, display, audio buses, controls, accessibility
  (reduce flashing, steering assist, auto-accelerate, colour-blind markers, HUD scale).

## Requirements
- Rust (stable, edition 2024) — `cargo`
- Node.js ≥ 22 and npm (to build the React UI bundle)
- A Vulkan-capable GPU (developed on an RTX 3070, Linux)

## Build & run
```sh
# 1. The UI bundle (ui/dist/{vendor,app}.js)
cd ui && npm install && npm run build && cd ..

# 2. The game
cargo run -p recharged
```
Run from the repository root. Saves, settings and logs go to your OS config dir
(`~/.config/recharged` on Linux); pass `--user-data-dir <path>` to keep them elsewhere.

UI development: `cd ui && npm run watch` hot-reloads the React app while the game runs.

## Controls (defaults, all rebindable)
| Action | Gamepad | Keyboard A | Keyboard B |
|---|---|---|---|
| Throttle / brake | RT / LT | W / S | ↑ / ↓ |
| Steer | Left stick / D-pad | A / D | ← / → |
| Drift | B / RB | Space | Right Shift |
| Use item (hold look back to fire backward) | A | E | Enter |
| Boost (spend charge) | X / LB | Left Shift | Right Ctrl |
| Look back | Y | Q | Numpad 0 / Delete |
| Reset (tap = flip, hold = respawn) | D-pad ↑ | R | Backspace |
| Camera | View | C | Numpad . / End |
| Pause | Start | Esc | Esc |

Menus: D-pad/stick or arrows/WASD to move, A/Enter/Space to confirm, B/Esc to go back, LB/RB or
Q/E to switch tabs; the mouse works too.

## Useful command-line flags
| Flag | Effect |
|---|---|
| `--quick-race <track> [--reverse] [--mirror] [--car <id>] [--ai <n>] [--laps <n>] [--weather <w>] [--time <t>] [--players <n>] [--mode tt\|versus\|cup:<id>]` | jump straight into a race |
| `--autopilot` | the AI drives the local players |
| `--unlock-all` | everything unlocked (not saved) |
| `--window <W>x<H>` | fixed window size |
| `--screenshot <png> [--screenshot-at <s>] [--screenshot-every <s>]`, `--exit-after <s>` | automated captures |
| `--track-tour <track>`, `--capture-previews` | screenshots along a track / preview images |
| `--headless-race`, `--bench <scenario>`, `--calibrate-medals`, `--soak <min>`, `--input-script <file>` | verification tools (see `docs/design/automation.md`) |

Tracks: `toy_town`, `sofa_circuit`, `backyard_bash`, `aisle_rush`, `wrench_works`, `maple_street`
(+ the dev track `test_oval`). Cars: `sparky`, `dumpster`, `zip`, `torque`, `hornet`, `phantom`,
`volt_gt`, `bolt`.

## Project layout
```
crates/
  rc_core      contracts: states, schedules, components, messages, catalog & settings types
  rc_track     track data → spline, geometry, colliders, racing line, props
  rc_vehicle   RC car physics (rapier), charge & boost
  rc_input     devices, bindings, player slots, menu navigation, rumble
  rc_weather   weather & time-of-day simulation
  rc_race      race rules: grid, phases, laps, standings, respawns, ghosts
  rc_ai        AI drivers, autopilot, steering assist
  rc_items     pickups, items, projectiles, status effects
  rc_camera    cameras, split-screen viewports
  rc_render    lighting, sky, materials, track/prop/car visuals, quality settings
  rc_vfx       particles, weather effects, name tags
  rc_audio     buses, engines, SFX, music director, ambience
  rc_game      game flow, modes, progression, saves
  rc_ui        bevy-react bridge (typed channels, HUD data)
  rc_testkit   headless test harness
  recharged    the binary
ui/            React/TypeScript UI (bevy-react)
assets/        data (RON), models, textures, audio, fonts
tools/         asset generators: Blender (cars, props), Python (SFX, music, textures)
docs/          GDD, architecture, practices, design notes, task briefs, reviews
```
The simulation crates run headless (no window/GPU/audio), which powers the integration, AI,
determinism and soak tests. Crate dependencies follow strict layers (core → simulation →
presentation → flow → UI); see `docs/ARCHITECTURE.md`.
